## 2024-06-22 - XSS Vulnerability in Setup Template via `text/template`
**Vulnerability:** The application was vulnerable to Cross-Site Scripting (XSS) due to the use of Go's `text/template` instead of `html/template` when rendering the `setup.html` page. The application constructed a `baseURL` using `r.Host` (which can be manipulated by an attacker via the Host header) and passed it to the template. Since `text/template` does not perform automatic contextual escaping of variables, an attacker could potentially inject malicious scripts into the rendered HTML response.
**Learning:** In Go, the `text/template` package does not escape output. This is highly dangerous when rendering HTML content with user-controlled input, even indirect inputs like HTTP headers.
**Prevention:** Always use `html/template` instead of `text/template` when generating HTML output in Go. The `html/template` package provides automatic, context-aware escaping (e.g., escaping differently inside HTML tags vs. JavaScript blocks) to prevent script injection vulnerabilities.
