## 2026-06-12 - Command Injection via Template Strings in Setup Scripts
**Vulnerability:** The setup script generation endpoint (`/setup`) in `server/internal/api/handlers.go` used `fmt.Sprintf` with double quotes to inject the `group` and `url` parameters directly into Bash and PowerShell scripts. Since the `group` query parameter is user-controllable, this led to a Command Injection vulnerability where an attacker could execute arbitrary commands when the generated script is run by passing a malicious group name (e.g., `"; malicious_command; #`).
**Learning:** Variables embedded in bash/powershell scripts via templates must be escaped properly and enclosed in single quotes. Double quotes allow string interpolation and command substitution.
**Prevention:** Always use single quotes when injecting variables into shell scripts from Go, and escape single quotes within the user input to prevent them from breaking out of the string context. Added `escapeBash` (`'\''`) and `escapePowerShell` (`''`) helper functions.
