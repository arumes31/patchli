## 2024-06-16 - SSRF Vulnerability in Webhook Verification
**Vulnerability:** The `isValidURL` function in `server/internal/webhooks/webhooks.go` contained commented-out code intended to block webhook requests directed at `localhost`, `127.0.0.1`, `::1`, and other private IP addresses (e.g. `10.0.0.0/8`, `192.168.0.0/16`). This allowed users to potentially provide internal application URLs to webhooks and force the server to perform requests against itself or other internal network applications (SSRF).
**Learning:** The validation code existed but was explicitly commented out, likely to allow local testing or out of a misunderstanding of how webhooks operate, leading to a serious security gap that exposed internal services.
**Prevention:** Always block local loopback and private network IP ranges for any user-supplied URL where the server will issue an HTTP request, unless there is a very strict and necessary whitelist. Never comment out critical security checks for testing; use flags or environment variables instead.
