## 2024-06-07 - [CRITICAL] Command Injection in Setup Scripts
**Vulnerability:** Setup script generation handlers (`generateLinuxScript`, `generateAlpineScript`, `generateWindowsScript`) in `server/internal/api/handlers.go` were directly injecting user input (e.g. `group` URL parameter) into shell scripts using double quotes (`"%s"`). This allowed critical command injection by supplying inputs containing `$()`, backticks, or variable expansions.
**Learning:** In this Go server, bash and PowerShell script templates are constructed via string formatting before being downloaded and executed on the client machine. The use of double quotes makes the injected variables subject to shell expansion before assignment, exposing a severe command injection surface.
**Prevention:** Always wrap dynamically interpolated script variables in single quotes (`'%s'`) instead of double quotes, preventing the host shell from interpreting enclosed characters. Additionally, apply custom escaping functions—such as replacing `'` with `'\''` for Bash and `''` for PowerShell—before string formatting.
