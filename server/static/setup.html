Add a Linux host

Works on Debian, Ubuntu and Alpine (systemd or OpenRC, amd64 or arm64). On the host, set RPATCH_ADMIN_TOKEN to the admin token and run the command below as root. Each run fetches a fresh one-time enrollment grant that is valid for 5 minutes. Re-running it on an enrolled host upgrades the agent.

curl --proto '=https' --tlsv1.2 -fsS -H "Authorization: Bearer $RPATCH_ADMIN_TOKEN" "{{.BaseURL}}/api/v1/setup?group=default&os=linux" | sudo sh
