Add New Agent

Follow this guided setup to register a new node into the Patchli fleet.

The installation script varies depending on the OS and init system.

Grouping helps you manage patch parallelism and maintenance windows.

Run this command on the target server as Administrator/root. This will download the agent, install the service, and perform initial registration.

curl -sSL {{.BaseURL}}/api/v1/setup?group=default&os=linux | sudo bash

Once the script finishes, your node will appear in the Inventory tab within 30 seconds.
